## Codebase Patterns
- Migrations use TypeORM MigrationInterface pattern with `up()` and `down()` methods
- Migration files follow naming: `{timestamp}-{PascalCaseDescription}.ts`
- Use `CREATE TABLE IF NOT EXISTS` pattern for idempotent migrations
- PostgreSQL UUID columns use `gen_random_uuid()` as default
- Timestamps use `TIMESTAMP DEFAULT CURRENT_TIMESTAMP`
- Create indexes separately after table creation
- Use `IF NOT EXISTS` and `IF EXISTS` clauses for idempotent operations
- Build verification: Use `pnpm run build` to verify TypeScript compilation (no separate typecheck script)
